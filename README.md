# simple-interest-calculator
A simple interest calculator project 
Project Description
this project calculates simple interest based on the principal amount, rate of interest, and time period.
Formula
Simple Interst=(Principal+rate+time)/100
inputs
.principal Amount
.Rate of interst
.Time period
Output
The calculator Simple interest.
Example
principal=1000
Rate=5%
TIME=2Years

simple interest=(1000+5+2)/100=100
